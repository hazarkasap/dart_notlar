# Dart Öğrenim Serüveni (Ders Notları)

Bu depo, Dart programlama dilini temelden ileri seviyeye öğrenirken tuttuğum ders notlarını ve uygulama örneklerini içermektedir. Tüm dosyalar, yeni başlayanlar için eğitici yorum satırlarıyla (GitHub Ders Notu formatında) zenginleştirilmiştir.

## 📂 Müfredat Yapısı

Dersler mantıksal bir sıra ile klasörlenmiştir:

1.  **[0_kurulumlar](./0_kurulumlar/):** Dart dünyasına giriş ve Merhaba Dünya.
2.  **[1_degiskenler](./1_degiskenler/):** Veri tipleri (int, double, String, bool, num, var) ve Interpolation.
3.  **[2_kontrol_dongu_yapilari](./2_kontrol_dongu_yapilari/):** If-else, Switch, For/While döngüleri ve Operatörler.
4.  **[3_fonksiyonlar](./3_fonksiyonlar/):** Fonksiyon tanımlama, Parametre türleri ve Fat Arrow kullanımı.
5.  **[4_koleksiyon_yapilari](./4_koleksiyon_yapilari/):** Listeler, Setler ve Map (Sözlük) yapıları.
6.  **[5_genel_tekrar](./5_genel_tekrar/):** Öğrenilenleri pekiştirmek için algoritma soruları ve çözümleri.
7.  **[6_nyp_oop_kavramlari](./6_nyp_oop_kavramlari/):** Nesne Yönelimli Programlama (Sınıflar, Kalıtım, Polimorfizm, Interface, Soyut Sınıflar).
8.  **[7_functional_programming_null_safety](./7_functional_programming_null_safety/):** Lambda ifadeleri, Higher Order Functions ve modern liste metotları.

## 🚀 Başlangıç

Bu depoyu yerel makinenize klonlayarak kodları inceleyebilir ve çalıştırabilirsiniz:

```bash
git clone https://github.com/kullanici_adi/dart_dersleri.git
cd dart_dersleri
```

Örnek bir dosyayı çalıştırmak için:
```bash
dart 1_degiskenler/string_veri_tipi.dart
```
